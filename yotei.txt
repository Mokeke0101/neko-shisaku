# ねこきめ 予定のテキスト（季節と行事の見た目を出す期間）
#
# 書き方
# - 1行に1つ、「名前：○日前から ○日後まで」と書きます。数字は全角でも半角でも読めます。
# - 行事は、行事の日から数えます。
#     例）クリスマス：20日前から 0日後まで　→　12月5日から12月25日まで
# - 季節は、季節の期間（境目の日から、次の季節の境目の前の日まで）の、
#   はじめから「何日前」、おわりから「何日後」と数えます。
#     例）秋：0日前から 0日後まで　→　9月1日から11月30日まで
#     例）秋：5日前から 0日後まで　→　8月27日から11月30日まで（夏と5日重なる）
# - 見た目を出さない行事は「名前：出さない」と書きます。季節は出さないにできません。
# - 「#」から行の終わりまでは、メモです。アプリは読みません。
# - 日数は 120日までです。
#
# 重なり
# - 行事どうし、季節どうしの期間が重ならないように書いてください。
# - 重なっていると、アプリの「せってい」の「季節と行事」と、確かめる道具（tools/yotei.mjs）が知らせます。
# - 重なった日は、季節は境目どおりの季節を出し、行事は期間の短い行事の飾りを出します
#   （期間が同じ長さなら、行事の日がその日に近い方）。
# - 夏祭り・花火と世界猫の日の毎年2日（8/7〜8/8）の重なりは、意図して残しています（世界猫の日を出します）。
#
# 行事の日（2026〜2030年のカレンダーは js/calendar.js にあります）
# - 節分・お月見は、年で日付が動きます（節分 2/2〜2/3、お月見 9/12〜10/3）。
# - 花見（4/1）・夏祭り・花火（8/1）は、日付の決まらない行事のため、目安の日を置いています。
